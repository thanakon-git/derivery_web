# ระบบจัดเส้นทางและแบ่งงานไรเดอร์อัจฉริยะ (ส่งด่วนมื้อเที่ยง) 🍱🛵
### Smart Lunchbox Delivery & Rider Route Optimization System (Mahasarakham University)

ระบบวางแผนจัดเส้นทางและกระจายงานไรเดอร์สำหรับร้าน **"ข้าวกล่องเดลิเวอรี ส่งด่วนมื้อเที่ยง"** เพื่อแก้ปัญหาออเดอร์มื้อเที่ยงไหลเข้ามาพร้อมกัน 20-30 รายการรอบมหาวิทยาลัยมหาสารคาม (มมส. ขามเรียง) ในรัศมี 3 กิโลเมตร โดยอาหารปรุงเสร็จ 11:30 น. และต้องนำส่งถึงมือลูกค้าทุกคนก่อน 12:30 น. (ภายในเวลา 1 ชั่วโมง) พร้อมควบคุมต้นทุนค่าส่งและคำนวณกำไรสุทธิตามสูตรจริงของร้าน

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **Frontend**: 
  - **Angular (v19/v21)** Standalone Components
  - **TailwindCSS** สำหรับ UI & Responsive Design
  - **Leaflet / OpenStreetMap** สำหรับแผนที่แบบ Interactive แสดงเส้นทางแยกสีของไรเดอร์แต่ละคัน
  - **Google Maps Navigation Integration** เชื่อมต่อ GPS นำทางแบบเลี้ยวต่อเลี้ยวสำหรับไรเดอร์
- **Backend**:
  - **Node.js** + **Express** + **TypeScript**
  - **VRP Solver Algorithm**: การจัดกลุ่มพิกัดเชิงมุมและระยะทาง (Spatial Sweep & Proximity Clustering) และ TSP 2-Opt Sequence Optimization
  - **Financial Calculator**: คำนวณต้นทุนอาหาร ค่าจ้างไรเดอร์ และกำไรสุทธิตามสูตรเฉพาะของร้าน
  - **Persistent Database**: ระบบฐานข้อมูล JSON บันทึกข้อมูลแบบ Real-time บนเซิร์ฟเวอร์ พร้อม Seed Data ลูกค้า 30 จุดรอบ มมส.

## 📐 กฎเกณฑ์ทางธุรกิจและการคำนวณ (Business & Cost Model)

1. **ราคาขายข้าวกล่อง**: 65 บาท / กล่อง
2. **ต้นทุนค่าอาหาร**: 40 บาท / กล่อง
3. **ค่าจ้างไรเดอร์ต่อรอบ**:
   $$\text{ค่าจ้างไรเดอร์} = 15 \text{ บาท (ค่าเรียก)} + (\text{ระยะทางรวม (กม.)} \times 2 \text{ บาท} \times \text{จำนวนกล่องรวมในรอบนั้น})$$
4. **ข้อจำกัดไรเดอร์**:
   - ไรเดอร์ 1 คน รับงานได้ **ไม่เกิน 3 ออเดอร์** ต่อรอบ
   - ความเร็วเฉลี่ย 30 กม./ชม. + เวลาจอดส่งมอบ 3 นาทีต่อจุด
   - ต้องส่งถึงลูกค้าจุดสุดท้าย **ก่อน 12:30 น.** (ภายใน 60 นาที)

## 🚀 วิธีการติดตั้งและเริ่มใช้งาน (Getting Started)

### 1. ติดตั้ง Dependencies (ครั้งแรก)
ติดตั้ง dependencies ใน Root, Backend และ Frontend:
```bash
# ติดตั้ง root
npm install

# ติดตั้ง backend
cd backend
npm install

# ติดตั้ง frontend
cd ../frontend
npm install
```

### 2. วิธีการรันโปรเจกต์ (Running the Application)

#### วิธีที่ 1: รันพร้อมกันทั้งระบบ (แนะนำ)
จากโฟลเดอร์ Root (`delivery/`):
```bash
npm run dev
```

#### วิธีที่ 2: รันแยกทีละส่วน
**รัน Backend (Port 3000):**
```bash
cd backend
npm run dev
```
*(เซิร์ฟเวอร์จะเปิดที่ `http://localhost:3000`)*

**รัน Frontend (Port 4200):**
```bash
cd frontend
npm start
```
*(เข้าใช้งานเว็บผ่านเบราว์เซอร์ที่ `http://localhost:4200`)*

## 🖥️ ฟังก์ชันการทำงานหลัก (Key Features)

### 1. หน้าจอสำหรับเจ้าของร้าน (Store Owner)
- **แผนที่เส้นทางอัจฉริยะ (Interactive Map)**: แสดงหมุดร้านค้า และหมุดลูกค้าจุดส่งของไรเดอร์แต่ละคน **แยกตามสีอย่างชัดเจน** พร้อมลากเส้นนำทางการวิ่ง
- **ตัวเลือกอัลกอริทึม (Alternative Strategies)**:
  - 🌟 **แบ่งตามโซนและระยะทาง (Smart Sector & Proximity)**: ป้องกันการวิ่งข้ามฝั่งเมือง ไม่ให้ไรเดอร์วิ่งทับทางกัน
  - 💰 **อัดเต็ม 3 ออเดอร์ (Min Riders)**: ใช้จำนวนไรเดอร์น้อยที่สุดเพื่อประหยัดค่าเรียก 15 บาท
  - ⚡ **กระจายงานเร็วสุด (Fastest Delivery)**: เน้นส่งถึงมือลูกค้าทุกคนอย่างรวดเร็วที่สุด
- **แดชบอร์ดภาพรวมการเงิน (Financial KPIs)**:
  - คำนวณยอดขายรวม, ต้นทุนอาหาร, ค่าจ้างไรเดอร์แต่ละคัน และ **กำไรสุทธิ** พร้อมแสดงสถานะกำไร/ขาดทุน
  - แสดงเวลาส่งของคันที่นานที่สุด พร้อมเครื่องหมายรับประกันทัน 12:30 น. (ภายใน 1 ชั่วโมง)
- **ระบบจำลองคำสั่งซื้อ (Order Simulation)**: ปุ่มจำลอง 20-30 ออเดอร์ช่วง 10:00 น. เพื่อทดสอบระบบได้ทันทีในคลิกเดียว

### 2. หน้าจอมือถือสำหรับไรเดอร์ (Rider Mobile View)
- เข้าใช้งานได้ผ่าน URL `/rider` หรือกดลิงก์จากการ์ดของไรเดอร์
- กรอกรหัสใบงาน เช่น `JOB-01`, `JOB-02` หรือเลือกรหัสงานด่วน
- **สรุปจำนวนข้าวกล่องที่ต้องหยิบจากร้าน**: แสดงตัวเลขขนาดใหญ่ชัดเจน (เช่น 7 กล่อง)
- **ลำดับจุดส่งเรียงตามเส้นทางสั้นสุด**: "จุดที่ 1 $\rightarrow$ จุดที่ 2 $\rightarrow$ จุดที่ 3"
- **ปุ่มเปิด Google Maps นำทาง**: กดครั้งเดียวจะเปิด Google Maps นำทางแบบ GPS ไปยังพิกัดของลูกค้ารายนั้นทันที
- ปุ่มอัปเดตสถานะงาน: "รับข้าวออกจากร้านแล้ว" และ "ส่งครบทุกจุดเรียบร้อย"
